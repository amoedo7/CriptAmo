# Security Policy

CriptAmo es software experimental y **no está auditado para proteger fondos reales**.

## No reportar públicamente

Nunca incluyas en Issues, commits o capturas:

- private keys;
- seed phrases / mnemónicos;
- archivos de wallet;
- passwords o PIN;
- API keys de exchanges o proveedores.

## Pruebas

Usar únicamente material criptográfico desechable creado para testing. No importar secretos que controlen activos reales.

## Hallazgos

Si detectás una debilidad en generación de entropía, derivación, serialización de claves o validación de direcciones, documentá el comportamiento reproducible usando claves de prueba sin valor.

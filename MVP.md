# MVP · CriptAmo

**Estado: HISTÓRICO / EXPERIMENTAL.**

No se promueve a wallet ni custodia.

Si se retoma, el único MVP aceptable inicialmente es educativo/testnet:
1. una única entrada canónica;
2. generación/derivación sólo con datos desechables;
3. vectores de prueba deterministas;
4. separación librería/UI;
5. ninguna seed/private key en logs;
6. advertencia test-only visible;
7. revisión criptográfica antes de cualquier uso con valor.

Nunca usar claves que protejan fondos reales como prueba del MVP.
